# Booka SIAS Implementation Roadmap

## Goal

Turn Booka from booking software into an AI-native operating layer for service businesses.

## 1. Product Changes

### Now
- Replace generic booking language with managed outcome language across the public site and core dashboard.
- Make onboarding feel like setup for a digital front desk rather than a software wizard.
- Surface outcome signals: no-show reduction, revenue recovery, repeat booking lift, and reactivation lift.
- Add clear escalation paths for exceptions, refunds, conflicts, and sensitive cases.

### Next
- Ship vertical packages for Beauty, Hospitality, and Medicine.
- Bundle templates, flows, KPIs, and escalation rules per vertical.
- Add operational memory views so tenants can see what Booka has learned.

## 2. Technical Changes

### Now
- Persist SIAS defaults in tenant settings during onboarding.
- Create shared config for vertical packages, pricing, and outcome attribution.
- Wire billing and onboarding to the same package definitions.

### Next
- Build a campaign engine with retries, audit logs, and attribution.
- Add human escalation queues for exception handling.
- Persist tenant memory for preferences, patterns, and operational notes.
- Attribute outcomes to campaigns, reminders, deposits, and recovery flows.

## 3. Pricing Changes

### Now
- Position pricing as subscription + usage + managed service tier.
- Stop presenting Booka as a generic software plan.

### Next
- Add outcome-based or revenue-band pricing for tenants that want managed operations.
- Introduce package-specific pricing for Beauty, Hospitality, and Medicine.
- Separate platform fee, messaging/AI usage, and managed service add-ons.

## 4. Launch Messaging

### Now
- Lead with “AI operations assistant for service businesses.”
- Use “automated front desk,” “revenue recovery,” and “customer operations layer” as the core phrases.

### Next
- Publish vertical-specific landing pages.
- Show concrete outcomes, not feature lists.
- Use managed onboarding and human escalation as proof of service quality.

## 90-Day Priority Stack

1. Public repositioning and onboarding.
2. Outcome attribution and billing language.
3. Human escalation workflows and campaign engine.
4. Tenant memory and vertical packages.
5. Managed pricing and launch pages.
