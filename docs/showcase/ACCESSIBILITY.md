# Accessibility review

Reviewed: semantic `main` landmarks, labelled local forms, native buttons and links, visible browser focus styles, readable disclosure copy, stock-image alt text, and local-only form confirmation text. No modal controls are used.

Release verification (deployable environment): keyboard traversal including demo headers and forms; contrast in each themed demonstrator; 200% zoom/reflow; reduced-motion preference; and the responsive screenshot set. Any focus, contrast, or overflow finding is a release blocker.
